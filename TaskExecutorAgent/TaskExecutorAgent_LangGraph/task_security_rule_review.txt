Implement a secure user lookup service that safely handles untrusted input.

Requested implementation:
- Create a user lookup service with a method:
  1) GetById(user_id) -> User or not-found result
- Accept user_id from an external request or command-line input.
- Store users in SQLite or the selected language's standard-library database API.
- Add a repository/data-access layer and a service layer.
- Add input validation for user_id.
- Add unit tests for valid IDs, missing IDs, malformed IDs, and database failures.

SECURITY SCENARIO:
- The user ID comes from an external request or command-line argument and may contain malicious SQL-like input.
- Use parameterized SQL queries or an equivalent safe query API.
- Never concatenate or interpolate user-controlled input into SQL statements.
- The code and tests must make the safe query behavior clear.
